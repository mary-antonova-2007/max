# Android MAX

Отдельное виртуальное Android-устройство для MAX. Его данные находятся в `avd`, Android SDK — в `sdk`. Папки Windows внутрь Android не подключаются. Камеры, звук, GPS отключены; доступ MAX к контактам, SMS, геопозиции, микрофону и камерам блокируется при запуске.

- `start.cmd` — запуск MAX.
- `stop.cmd` — остановка Android.
- `send-file.cmd` — выбрать файл через диалог или перетащить один файл на эту команду, чтобы скопировать его в Android: папка «Загрузки». Затем выберите его в MAX.
- `receive-files.cmd` — вручную скопировать Android «Загрузки» в папку `outbox` рядом со скриптом и открыть её в Проводнике. Файлы из Android `Downloads/MAX` появятся в `outbox/MAX`.
- На текущем ПК созданы ярлыки «В MAX - передать файл» и «Из MAX - получить файлы» для этих команд. Скрипт установки ярлыки не создаёт. Эмулятор должен быть запущен. Команды копируют файлы, оригиналы остаются на месте; повторное получение обновляет одноимённые локальные копии.
- `update.cmd` — скачать официальный APK MAX и обновить установленное приложение без сброса данных. Android должен быть запущен.

## Клавиатура Windows

В Windows выберите английскую раскладку. В Android откройте Settings → System → Languages & input → Physical keyboard → qwerty2 и добавьте English (US) и Russian. В текущем локальном устройстве они уже добавлены. Раскладка Android переключается отдельно от Windows сочетанием **Ctrl + Пробел**.

Запуск использует `QtRawKeyboardInput` с отключённым `KeycodeForwarding`. В Extended Controls → Settings переключатель **Enforce keycode forwarding** должен быть выключен: он несовместим с этим режимом. Настройки раскладок сохраняются в данных Android.

Статус проверки: Android получает клавиши-модификаторы из Windows; полный ввод русского текста и переключение с физической клавиатуры пока не подтверждены.

## Локальная конфигурация

Необязательный `config.local.json` с полем `PhoneNumber` задаёт номер виртуального модема. Файл исключён из Git. Это параметр эмуляции, а не настоящая SIM-карта. Данные Android, SDK, загрузки и папки обмена также исключены из Git.

## Подготовка среды

`setup.ps1` распаковывает уже скачанные официальные архивы; автоматической загрузки SDK в нём пока нет. Перед запуском нужно подготовить `downloads/platform-tools.zip`, `downloads/emulator.zip` и `downloads/system.zip` (Google APIs Android 11 x86_64). Они должны соответствовать закреплённым SHA-1 в `$packages` внутри `setup.ps1`; произвольные новые версии проверку не пройдут. На Windows должна быть включена Windows Hypervisor Platform.

После подготовки среды запустите `start.cmd`, затем `update.cmd` для установки MAX. APK берётся с https://download.max.ru/android/release/google/MAX.apk.

Эмулятор имеет доступ в сеть через Windows. Это изоляция данных приложения внутри виртуального Android; доступ из него к сетевым сервисам локальной сети отдельным межсетевым экраном здесь не блокируется. ADB предназначен для локального управления — не открывайте его порты наружу.

Авторизация выполняется пользователем внутри MAX. Требования сервера к паролю и входу сохраняются.
